# Portafolio 3D

Maneja el jeep por un pequeño mundo 3D y acércate a cada lugar para ver proyectos, empresas, logros y contacto.

- Hecho con [three.js](https://threejs.org).
- Modelos de naturaleza, pueblo y campamento: [Kenney](https://kenney.nl), con licencia CC0.
- "Wet Floor Sign" de louis-muir, con licencia CC BY 4.0.

Controles:
- **En computadora:** flechas o WASD para manejar y Espacio para frenar; arrastra el mouse para girar la vista y usa la rueda para acercar.
- **En celular:** botones en pantalla y pellizco para acercar.
